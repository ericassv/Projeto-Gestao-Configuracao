
# Projeto de Gestão de Configuração

## Objetivo
Organizar e controlar as alterações realizadas nos arquivos de um projeto de software utilizando Git e GitHub.

## Requisitos iniciais
- Criar e manter os arquivos do projeto.
- Registrar alterações por meio de commits.
- Manter o histórico das modificações.
- Disponibilizar os arquivos em um repositório remoto.
- Permitir a atualização dos arquivos versionados.

## Ferramentas
- Git
- GitHub
